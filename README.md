# CRUD 설계 과제 [8차시]

## 과제 소개
JPA 실습 내용을 바탕으로 본인 프로젝트에 필요한 CRUD 기능을 직접 설계하고 구현합니다.

## 과제 조건
- 7차시 과제 설계를 그대로 활용

## PR 양식
- 과제 주제
- ERD 이미지 첨부

- 각 클래스마다 어떤 기능을 담당하는지 설명
- 설계하면서 고민한점 / 어려웠던 점

## 📗 과제 제출 방법
&nbsp; 해당 설명에서 중괄호`{}` 된 부분은 예시이며 본인에게 맞게 바꿔서 작성하셔야 합니다.

**1. 해당 리포지토리 클론하기**
   ```
   git clone https://github.com/Likelion-YeungNam-Univ/14th-be-jpa-assignment.git
   ```

**2. 본인 깃허브 이름으로 된 브랜치 생성 - `feature/{깃허브 이름_차시}`**
   ```
   git checkout -b feature/{깃허브 이름}

   # 7차시 과제
   git checkout -b feature/lnahyun_7

   # 8차시 과제
   git checkout -b feature/lnahyun_8
   ```

**3. IntelliJ에서 해당 프로젝트 열기**

**4. src/ 내 프로젝트 작성**

**5. 작업 완료 후, 본인이 생성한 브랜치로 push**
   ```
   git push origin feature/{깃허브 이름_차시}

   # 7차시 과제
   git push origin feature/lnahyun_7

   # 8차시 과제
   git push origin feature/lnahyun_8
   ```

**6. Pull Request 작성**
PR 제목은 아래 형식으로 작성해주세요.
   ```
   BE 7회차 과제 - 이나현
   BE 8회차 과제 - 이나현
   ```

# 도메인 설계 과제

## 과제 소개
JPA 실습 내용을 바탕으로 직접 도메인을 설계하고 엔티티를 구현합니다.  
주제: 자유롭게 선택 가능 (게시판, To-do List etc..)


## 과제 조건
- Entity를 최소 5개 이상 설계할 것
- 6일차 과제 설계를 그대로 활용 가능

<br>

## 📗 과제 제출 방법
&nbsp; 해당 설명에서 중괄호`{}` 된 부분은 예시이며 본인에게 맞게 바꿔서 작성하셔야 합니다.

**1. 해당 리포지토리 클론하기**
   ```
   git clone https://github.com/Likelion-YeungNam-Univ/14th-be-jpa-assignment.git
   ```

**2. 본인 깃허브 이름으로 된 브랜치 생성 - `feature/{깃허브 이름}`**
   ```
   git checkout -b feature/{깃허브 이름}

   # 예시
   git checkout -b feature/lnahyun
   ```

**3. IntelliJ에서 해당 프로젝트 열기**

**4. src/ 내 프로젝트 작성**

**5. 작업 완료 후, 본인이 생성한 브랜치로 push**
   ```
   git push origin feature/{깃허브 이름}

   # 예시
   git push origin feature/lnahyun
   ```

**6. Pull Request 작성**
\- PR 제목: `BE 7회차 과제 - {이름}`
